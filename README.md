# Algerian Forest Fires FWI Prediction

Machine Learning project focused on predicting the Fire Weather Index (FWI) using the Algerian Forest Fires dataset.

## Project Overview
This project includes:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Regression Modeling
- Model Evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Goal
The objective is to build a regression model capable of predicting wildfire risk through Fire Weather Index (FWI) values.
